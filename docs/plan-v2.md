# 개복치 휴식 시뮬레이터 — 기획·밸런스 계획서 v3

2026-10-08 · 정채은

## 프로젝트 개요

정보디자인 A1 포스터 "내 휴식은 충분히 가치 있었을까?"를 5분짜리 브라우저 게임으로 옮긴다. 플레이어는 개복치를 데리고 하루를 여행하며 7번의 휴식을 선택하고, 마지막에 자기 하루가 포스터로 조립되는 것을 본다.

| 항목 | 내용 |
| --- | --- |
| 평가 기준 | 전달하려는 바의 가시성, 인터랙션의 재미, 인터랙션의 참신성 |
| 목표 플레이타임 | 5분 이내 |

수치는 모두 초안이며 실제 플레이 후 조정 대상이다. 모든 수치는 `state.js`에 상수로 둔다.

## 핵심 메시지와 설계 원칙

전달할 메시지는 하나다. **휴식의 가치는 금액이 아니라 주도성과 시야의 넓이가 결정했다.** 게임은 이 결론을 설명하지 않고 규칙으로 심어 둔다.

1. **돈은 거의 효과가 없다.** 지출 연출은 가장 화려하게, 실제 수치 변화는 가장 작게.
2. **주도성은 조작량으로 표현한다.** 멍때리기는 아무것도 안 하면 진행되고, 돌아다니기는 직접 드래그해야 한다.
3. **시야는 화면 폭으로 표현한다.** 좁은 장소에서는 화면이 좁아지고 넓은 풍경에서는 열린다.
4. **만족감은 숨긴다.** 플레이 중에는 통증과 의지만 보이고, 만족감은 결과 화면에서 처음 공개된다.
5. **랜덤은 장소와 이벤트에만.** 행동의 결과는 결정적이다. 이벤트도 판마다 정해진 틀 안에서 섞는다.
6. **결과를 조작하지 않는다.** 기록이 메시지와 다르게 나오면 그대로 보여 주고 계산식에 무엇이 들어갔는지 밝힌다.
7. **점수와 등급은 없다.** 엔딩은 개복치의 상태이고, 결과는 쉼의 유형이다.

## 전체 순서도

```
[인트로] 이름 · 여행지 선택
   ↓
[이동] 통증 증가 (턴마다 증가량 커짐)
   ↓
[돌발 이벤트] 세션 패턴으로 배정된 3개 턴에서만
   ↓
[장소 카드] 시야 등급 결정 ← ─────────┐
   ↓                                   │
[쉴까?]                                 │
   ├─ 왼쪽 스와이프 = 건너뛰기 (통증 +4) ┘
   └─ 오른쪽 스와이프 = 휴식
          ↓
      [행동 선택] 주도성에 따라 조작 방식이 다름
          ↓
      [결과] 통증·의지 갱신, 만족감은 숨겨서 기록
          ↓
      (7턴 반복)
   ↓
[엔딩 판정]  ← 의지 0 또는 통증 100이면 즉시 여기로
   ↓
[포스터 조립] 스크롤 4단계 → 실제 하루와 비교
```

건너뛰면 다음 장소로 넘어가되 통증 +4. 통증 80 이상이면 건너뛰기 카드가 잠기고 "몸이 대신 정했다."가 뜬다.

## 스탯 정의

| 스탯 | 범위 | 초기값 | 표시 | 역할 |
| --- | --- | --- | --- | --- |
| 발바닥 통증 | 0~100 | 15 | 보임 | 높을수록 나쁨. 행동 선택지를 잠근다 |
| 여행 의지 | 0~100 | 45 | 보임 | 0이 되면 조기 귀국 엔딩 |
| 예산 | ¥0~ | ¥8,000 | 보임 | 바닥나도 게임오버 아님. 지출 선택지만 비활성 |
| 만족감 | 휴식당 0~10 | — | **숨김** | 결과 화면에서만 공개 |

### 발바닥 통증

**이동 시 증가**

| 턴 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 증가량 | +8 | +9 | +11 | +12 | +14 | +16 | +18 |

하루가 끝나갈수록 같은 거리도 더 아프다(평발 경험).

**휴식 시 회복 효율** (행동의 회복량에 곱함)

| 현재 통증 | 회복 효율 |
| --- | --- |
| 0~39 | 1.0 |
| 40~69 | 0.75 |
| 70~100 | 0.5 |

통증이 쌓일수록 쉬어도 잘 안 풀린다. 후반부 긴장의 핵심.

### 여행 의지

```
Δ의지 = -3 + 주도성 + 시야 + 돈 보너스 + 통증 패널티
```

`-3`은 이동 기본 소모. 통증 패널티는 휴식 종료 시점의 통증으로 판정한다.

| 휴식 후 통증 | 패널티 |
| --- | --- |
| 0~39 | 0 |
| 40~59 | −3 |
| 60~79 | −6 |
| 80~100 | −10 |

### 돈 보너스

금액과 무관하게 **지출이 있으면 +1, 없으면 0**. 돈을 쓰면 조금 나아지지만 더 쓴다고 더 나아지지 않는다.

### 숨은 만족감

```
만족감 = 3 + 주도성/2 + 시야/2 + 돈 보너스 + 통증 패널티/2
```

0~10으로 반올림 후 자른다. 예: 돌아다니기 + 넓은 시야(통증 낮음) = 10, 스마트폰 + 좁은 시야 = 4, 디저트 + 좁은 시야 = 6.

## 장소 카드 덱

매 턴 덱에서 카드 한 장을 비복원 추출한다. 카드는 시야 등급과 실내 여부를 가지며, 실제 휴식 기록 9건에서 만든다.

| 시야 등급 | 의지 보너스 | 화면 폭 | 예시 장소 |
| --- | --- | --- | --- |
| 좁음 | +1 | 세로 창 (40%) | 쇼핑몰 내부, 창 없는 카페, 지하 통로 |
| 중간 | +3 | 기본 (70%) | 창가 카페, 골목, 공원 벤치 |
| 넓음 | +7 | 파노라마 (100%) | 강변, 전망대, 스카이라인 |

### 여행지별 덱 (9장 중 7장 추출)

| 여행지 | 좁음 | 중간 | 넓음 | 턴당 기대 시야 보너스 |
| --- | --- | --- | --- | --- |
| 도시 (하드) | 5 | 3 | 1 | 2.3 |
| 마을 (노말) | 3 | 4 | 2 | 3.2 |
| 바닷가 (이지) | 2 | 3 | 4 | 4.3 |

난이도는 예산이 아니라 **시야 분포**로 표현한다.

### 실내 플래그

`indoor: true` 카드(카페, 쇼핑몰 등)에서는 **주변 돌아다니기**를 선택할 수 없다.

## 행동 선택지

포스터 2층의 주도성 축을 따른다. **조작 방식이 주도성을 몸으로 전달하는 장치**이므로 수치보다 중요하다.

| 행동 | 주도성 | 통증 회복 | 지출 | 조작 방식 | 사용 조건 |
| --- | --- | --- | --- | --- | --- |
| 멍때리기 | +1 | −14 | — | 6초 무입력 | 없음 |
| 스마트폰 | 0 | −12 | — | 1회 탭 후 방치 | 없음 |
| 디저트 | +2 | −9 | ¥600~1,200 | 1회 탭 | 예산 충분 |
| 식사 | +3 | −11 | ¥900~1,800 | 1회 탭 | 예산 충분 |
| 잡담 | +4 | −10 | — | 1회 탭 | 통증 < 85 |
| 계획 짜기 | +6 | −5 | — | 항목 2개 드래그 정렬 | 통증 < 80 |
| 주변 돌아다니기 | +7 | −3 | — | 개복치를 직접 드래그 이동 | 통증 < 65, 실내 아님 |

- **통증 회복과 주도성이 반비례한다.** 의지를 올리는 행동은 발을 쉬게 못 하고, 발을 쉬게 하는 행동은 의지를 못 올린다. 이것이 게임의 중심 긴장.
- **통증 65가 분기점.** 넘으면 돌아다니기가 잠기고 후반에 발과 의욕이 같이 꺾인다.
- **통증 80 이상 = "몸이 대신 정했다".** 건너뛰기·계획·돌아다니기가 잠긴 상태를 문구 하나로 묶어 보여 준다.

### 멍때리기의 무입력 처리

선택지가 다 나타난 뒤 무입력 6초가 지나면 자동으로 멍때리기 실행. 3초부터 화면이 서서히 흐려지며 예고하고, 포인터 이동·터치 시 타이머 리셋. 실행되면 개복치가 멍한 표정이 되고 **"아무것도 안 했다. 개복치도."**가 뜬다.

## 돌발 이벤트

게임 시작 때 이벤트 턴과 종류를 미리 정한다. 한 판에 정확히 3회, 턴당 최대 1회, 세 슬롯은 서로 다른 턴.

| 슬롯 | 배정 턴 | 후보 풀 |
| --- | --- | --- |
| 유혹 | 3~5턴 중 하나 | 한정 디저트 (고정) |
| 부정 | 2~6턴 중 하나 | 발을 삐끗, 비 |
| 긍정 | 2~6턴 중 하나 | 축제 발견, 개복치의 제안, 벤치 발견 |

해당 턴에 조건이 안 맞으면 같은 풀의 다른 이벤트로 바꾸고, 하나도 안 맞으면 이벤트 없이 지나간다.

| 이벤트 | 발생 조건 | 선택지 | 결과 |
| --- | --- | --- | --- |
| 한정 디저트 | 항상 등장 (예산 ¥2,500 미만이면 "산다" 비활성) | 산다 | 의지 +3, 통증 −10, ¥2,500 |
| | | 지나친다 | 변화 없음 |
| 발을 삐끗 | 통증 30 이상 | — | 통증 +10, 의지 −5 |
| 비 | 5턴차 이전 | — | 다음 턴 시야 한 단계 하락 |
| 축제 발견 | 실외 카드 | 구경한다 | 이번 턴 시야 '넓음'으로 승격, 의지 +4 |
| | | 지나친다 | 의지 −2 |
| 개복치의 제안 | 3턴차 이후 | 따라간다 | 다음 장소 카드 교체, 의지 +4 |
| | | 거절한다 | 의지 −2 |
| 벤치 발견 | 통증 50 이상 | — | 통증 −8 |

- **한정 디저트는 함정이다.** ¥2,500에 의지 +3(돌아다니기는 공짜로 +7). 연출은 가장 화려하게.
- **축제는 유일한 시야 역전 수단.** 도시 덱의 숨통.

## 밸런스 기준값 (이벤트 제외)

구현 후 아래 경로를 돌려 비슷하게 나오는지 확인한다.

| 경로 | 여행지 | 최종 의지 | 최종 통증 | 만족감 평균 | 잔액 |
| --- | --- | --- | --- | --- | --- |
| 돌아다니기 올인 | 바닷가 | 80 | 76 | 6.9 | ¥8,000 |
| 영리한 혼합 | 마을 | 77 | 53 | 6.6 | ¥8,000 |
| 계획 위주 | 마을 | 76 | 73 | 6.4 | ¥8,000 |
| 영리한 혼합 | 도시 | 68 | 39 | 6.0 | ¥8,000 |
| 돈 쓰기 | 도시 | 60 | 33 | 6.0 | ¥1,400 |
| 스마트폰만 | 도시 | 43 | 19 | 4.6 | ¥8,000 |

지켜야 할 것: 돈 쓰기 경로가 중하위권, 스마트폰만은 통증 최저·만족감 꼴찌, 어떤 단일 행동도 지배 전략이 되지 않음.

조정 포인트:
- 조기 귀국 엔딩(의지 0)이 거의 안 나온다. 보고 싶으면 기본 소모를 −4로 올리고 엔딩 구간도 같이 조정.
- 이벤트 포함으로 다시 돌려 최종 의지가 ±5 이상 흔들리면 이벤트 수치를 낮춘다.

## 결과 화면과 엔딩

### 엔딩 분기

| 조건 | 엔딩 | 개복치 상태 |
| --- | --- | --- |
| 의지 0 도달 | 조기 귀국 | 숙소로 돌아가 버림 |
| 통증 100 도달 | 발이 먼저 끝냈다 | 더 못 걷고 주저앉음 |
| 7턴 완주, 의지 70+ | 좋은 하루 | 팔딱거림 |
| 7턴 완주, 의지 40~69 | 무난한 하루 | 평온함 |
| 7턴 완주, 의지 40 미만 | 길었던 하루 | 지침 |

점수·랭크 표시는 넣지 않는다.

### 포스터 조립 (스크롤 4단계, ScrollTrigger scrub)

0. **(시간 남으면) 개복치 해체** — 개복치 SVG가 점으로 흩어져 7개 막대 자리로 날아가 쌓인다. GSAP 타임라인 하나.
1. **만족감 막대 7개** — 숨겨 두었던 값 공개. 돈 쓴 휴식은 초록, 안 쓴 휴식은 회색, 지출이 클수록 진함.
2. **금액 선** — 막대 위에 지출액을 선으로 연결.
3. **통증 점선과 의지 면** — 하루의 발바닥 곡선과 의욕 곡선.
4. **행동·공간 연결선** — 각 막대에서 그때 고른 행동과 장소 실루엣으로 선이 이어진다.

### 마지막 숫자 두 개

**"돈을 쓴 휴식 평균 ○○ / 돈을 안 쓴 휴식 평균 ○○"** (플레이어 기록으로 계산)

| 경우 | 문구 |
| --- | --- |
| 돈 쓴 평균 ≤ 안 쓴 평균 | 돈을 쓴 휴식이 더 좋았던 건 아니었다. |
| 돈 쓴 평균 > 안 쓴 평균 | 이번에는 돈을 쓴 휴식이 더 좋았다. 그때 어디에 있었는지 아래에서 확인해 보자. |
| 한 번도 안 씀 / 매번 씀 | 비교할 짝이 없다. 대신 세 휴식을 보자. |

모든 경우 아래에 작게: **"만족감 계산에는 '돈을 썼는지'만 +1로 들어갔다. 금액은 들어가지 않았다."**

### 세 휴식 강조

| 표시 | 기준 |
| --- | --- |
| 몸을 가장 쉬게 한 휴식 | 통증 감소량 최대 |
| 다시 걷게 한 휴식 | Δ의지 최대 |
| 가장 비쌌던 휴식 | 지출 최대 (지출 없으면 생략) |

셋이 서로 다른 막대면 "가장 비쌌던 휴식이 나를 다시 걷게 한 건 아니었다." 같은 막대면 "이번에는 가장 비쌌던 휴식이 가장 좋았다. 그때 시야는 ○○이었다." 동점이면 나중 턴.

### 쉼의 유형 (등급 아님)

7번의 휴식(건너뛴 턴 제외)의 평균 주도성·평균 시야 보너스로 2×2. 여기서 처음 "주도성"과 "시야"라는 축의 이름이 나온다.

| | 시야 평균 < 3.5 | 시야 평균 ≥ 3.5 |
| --- | --- | --- |
| **주도성 평균 ≥ 3.5** | 의도적인 쉼 | 열린 탐험가 |
| **주도성 평균 < 3.5** | 웅크린 쉼 | 풍경에 흘러가는 쉼 |

문구는 "당신은 이런 식으로 쉬었다"로만 쓴다.

그 아래 제작자의 실제 하루를 반투명하게 겹치고 토글로 번갈아 본다. 각주: 실제 기록은 하루 9건이며 통계가 아니라 한 사람의 하루다. 이 게임은 제작자의 결론을 규칙으로 번역한 것이지 증명이 아니다.

| --- | --- |
| 인트로·이름·여행지 | 30초 |
| 7턴 루프 (턴당 약 25초 + 이벤트 3회 × 6초) | 약 3분 20초 |
| 결과 조립 | 60초 |
| 비교·공유 | 30초 |

턴 25초 = 이동 4초 + 카드·스와이프 6초 + 행동 선택 8초 + 결과 7초.

- 모든 연출은 탭 한 번으로 스킵.
- 한 턴의 텍스트는 2줄 이내.
- 결과 조립에 "바로 보기" 버튼.
- 재플레이는 인트로 생략.

## 인터랙션 구현 매핑

| 인터랙션 | 붙는 곳 | 구현 | 우선순위 |
| --- | --- | --- | --- |
| 카드 스와이프 | 쉴까? 판정 | GSAP Draggable, 기울기에 따라 "+통증" 미리보기 | 필수 |
| 시야 = 화면 폭 | 장소 도착 | `clip-path` 보간, 40% / 70% / 100% | 필수 |
| 주도성 = 입력량 | 행동 선택 | 행동별 조작 분기 (대기·탭·드래그) | 필수 |
| 포스터 스크롤 조립 | 결과 | ScrollTrigger scrub 4단계 | 필수 |
| 개복치 상태 표현 | 전 구간 | 통증 → 가라앉음 `y = (통증 − 50) × 0.6px`. 의지 → 유영: 커서 lerp 계수 `0.03 + 0.09 × 의지/100`, 흔들림 진폭도 의지 비례 | 시간 남으면 (1순위) |
| 통증 화면 왜곡 | 이동 구간 | CSS `filter`·`transform` 흔들림, 통증 비례 | 시간 남으면 |
| 돌발 이벤트 전면 전환 | 이벤트 | 풀스크린 오버레이 + 글자 단위 등장 | 시간 남으면 |
| 개복치 해체 → 막대 | 결과 진입 | GSAP 타임라인, SVG 원 30~50개 | 시간 남으면 |
| 실제 하루 겹치기 | 결과 끝 | SVG 두 레이어 토글 | 시간 남으면 |

**쓰지 않는 것:** Three.js, WebGL 셰이더, 환경음.

### 모바일 대응

- 커서 추종 → 터치 지점으로 헤엄쳐 가는 방식.
- 시야 마스크는 세로 화면에서 상하로 열림.

### 휴식 기록 JSON

장소 카드 덱과 결과 비교 레이어의 원본.

```json
{
  "date": "2026-XX-XX",
  "city": "",
  "rests": [
    {
      "id": 1,
      "time": "10:40",
      "place": "",
      "placeType": "shopping | cafe | park | riverside | street",
      "view": "narrow | mid | wide",
      "indoor": true,
      "spend": 0,
      "action": "spacing | phone | dessert | meal | chat | plan | wander",
      "satisfaction": 0,
      "painBefore": 0,
      "painAfter": 0,
      "driveBefore": 0,
      "driveAfter": 0,
      "note": ""
    }
  ]
}
```

`view`·`indoor` → 장소 카드, `satisfaction`·`painAfter`·`driveAfter` → 결과 비교 레이어.

### 파일 구성

```
src/
  main.js          엔트리, 씬 전환
  state.js         스탯 갱신식 (이 문서의 수치를 상수로)
  deck.js          장소 카드 덱 생성과 추출
  events.js        돌발 이벤트 6종 + 세션 패턴 배정
  scenes/
    intro.js       이름·여행지 선택
    turn.js        이동 → 카드 → 쉴까 → 행동 → 결과
    ending.js      엔딩 판정
    poster.js      스크롤 조립 + 비교
  data/
    rests.json     실제 휴식 기록 9건
```

## 제작 일정

| 날짜 | 작업 |
| --- | --- |
| 10/8 (목) | 휴식 기록 9건 JSON 정리 |
| 10/9 (금) | 포스터 결과 화면 (스크롤 조립) |
| 10/10 (토) | 핵심 루프 7턴 |
| 10/11 (일) | 시야 · 연출 · 모바일 대응 |
| 10/12 (월) | 배포 · 저널 — **23:59 마감** |
