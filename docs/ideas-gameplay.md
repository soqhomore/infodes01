# 게임성 브레인스토밍 아이디어 맵

2026-10-11 · 전달 의도("휴식의 가치는 금액이 아니라 주도성과 시야의 넓이가 결정한다")를 유지하면서 게임성을 높이는 방향 탐색.

---

## A. 체감 재미 — 조작감·피드백·리듬

### A1. 행동별 조작 차이 극대화 ★★★
현재 "주도성 = 조작량"이 핵심 설계인데, 멍때리기(무입력)와 돌아다니기(드래그) 외에는 대부분 탭 한 번.

- **스마트폰**: 탭 → 화면이 좁아지며 스크롤 피드 애니메이션 (주도성 0의 "빨려 들어가는 느낌")
- **디저트/식사**: 탭 → 동전 떨어지는 짧은 애니메이션 (돈의 화려한 연출, 실제 효과는 미미)
- **잡담**: 말풍선이 하나씩 올라옴 (2~3번 탭)
- **계획 짜기**: 원래 기획의 드래그 정렬 복원 (항목 2개 순서 정하기)
- **멍때리기**: 화면 전체가 천천히 바다색으로 물드는 연출 (WebGL 배경과 연결)

**메시지 기여**: 주도성을 "손으로 느끼게" 함 — 몸을 많이 쓸수록 능동적 휴식임을 체감

### A2. 통증이 체감되는 화면 반응 ★★
plan-v2의 "통증 화면 왜곡"을 간단하게:
- 통증 60+: 화면 미세 흔들림 (CSS transform)
- 통증 80+: 화면 가장자리 붉어짐 (CSS vignette)
- 이동 시 통증 증가 순간: 짧은 진동 (navigator.vibrate, 모바일)

**메시지 기여**: 몸의 한계를 시각으로 느끼게 함

### A3. 리듬 변주 — 같은 루프의 반복을 깨기 ★
매 장소 [도착 → 행동 → 결과 → 더 쉴까?]가 동일 패턴. 변주를 주면:
- **시간대별 분위기 전환**: 아침엔 빠르게, 노을엔 여운, 밤엔 텍스트 느리게
- **이동 중 독백**: 가끔 한 줄 ("발이 조금 무거워졌다", "바람이 분다")
- **3·6번째 방문쯤 "숨 고르기"**: 개복치가 잠깐 멈추고 하늘을 올려다보는 연출

**메시지 기여**: 간접적. 반복감 해소

---

## B. 선택의 깊이 — 매 판이 다르게 느껴지는 것

### B1. 장소 개성 강화 ★
현재 장소는 시야(narrow/mid/wide)와 실내 여부만 차이. 고유 특성을 주면:
- 특정 장소에서만 가능한 행동 변형 (강변: "물멍", 공원: "산책"으로 이름 변경)
- 장소 분위기 텍스트 1~2줄 ("조용한 카페다. 계획을 짜기 좋겠다")

### B2. "다음 장소 예고"의 전략적 활용 ★★
day-logic에 이미 "다음 장소·시야·이동 시간 예고" 규칙이 있음. 이걸 시각적으로 강조하면:
- 다음이 wide → "지금 좀 더 쉬어도 괜찮겠다" 판단
- 다음 이동 시간이 길면 통증 관리 긴장감
- **정보를 보는 것 자체가 전략적 판단** → 단순 반복이 아닌 상황별 의사결정

### B3. 이벤트 임팩트 강화 ★★★
현재 이벤트가 텍스트 박스 + 버튼. 선택의 무게감을 높이면:
- **한정 디저트(함정)**: 화면 전체 반짝임, "특별한 기회!" 유혹 연출 → 결과에서 만족감 미미 → "속았구나"
- **축제 발견**: clip-path가 40%→100%로 열리는 극적 애니메이션 → "시야가 이렇게 다르구나" 체감
- **개복치의 제안**: 개복치가 방향을 가리키는 비주얼 → 따라가면 좋은 시야

**메시지 기여**: "돈의 화려함 vs 실제 효과"를 극적으로 체감 (한정 디저트). "시야가 넓어지는 경험"을 감각으로 전달 (축제)

### B4. 귀환 타이밍의 의미 ★★
자발적 귀환에 서사적 의미 부여:
- 통증 낮고 마음 높을 때 일찍 귀환 → "여유 있게 마친 하루"
- 끝까지 버티다 21시 → "알찬 하루" 또는 "욕심부린 하루"
- 결과에서 "언제 돌아왔는지"가 축이 되면 → **"적절히 멈추는 것도 주도성"**

**메시지 기여**: 주도성의 의미를 "더 하는 것"에서 "멈추는 것"으로 확장

---

## C. 감정적 몰입 — 개복치와의 여행이 기억에 남는 것

### C1. 개복치의 존재감 ★★★
현재 SVG 원/이모지 수준. 작은 변화로 애착:
- **상태별 표정**: 단순 SVG (눈 2개 + 입) — 통증 높으면 처진 눈, 마음 높으면 반짝이는 눈
- **장소 반응 한 줄**: "개복치가 강을 보고 눈이 커졌다" (wide), "좁은 가게에서 어색해한다" (narrow)
- **커서 추종** (plan-v2): 마우스/터치를 따라다님. 의지 낮으면 느리게, 높으면 빠르게
  - 상태가 움직임으로 체감됨

**메시지 기여**: 숫자가 아닌 감정으로 상태를 읽게 함

### C2. 하루의 서사 아크 ★★
시간대 전환 시 한 줄 텍스트로 감정 곡선:
- 아침: "아직 발이 가볍다. 어디든 갈 수 있을 것 같다."
- 오후: "슬슬 발바닥이 말을 건다."
- 노을: "하루가 기울고 있다. 개복치가 하늘을 올려다본다."
- 밤: "돌아갈 시간이다."

### C3. 결과 화면의 감정적 재구성 ★★
현재 데이터 시각화 → "여행 일기" 느낌으로:
- 방문 장소 풍경이 작은 그림으로 이어지는 파노라마
- 각 장소 행동 아이콘 (zzz, 발자국, 케이크 등)
- **"가장 좋았던 순간"을 플레이어가 직접 고르게 하기** → 시스템 만족감과 비교
  → "내가 좋았다고 느낀 것과 나를 회복시킨 것이 다를 수 있다"

### C4. 시드 공유와 비교 ★
- 결과에서 "다른 여행지였다면?" 힌트 → 재플레이 동기
- 시드 공유 → 같은 여행을 친구가 해보고 결과 비교
- 정보디자인 수업의 소통 효과

## E. 주의사항

- 게임 수치(state.js 상수)는 변경하지 않는다.
- 메시지를 "설명"하는 것이 아니라 "규칙으로 심어두는" 것이 핵심 원칙.
- 모든 아이디어는 현재 스택(Vite, GSAP, vanilla JS, SVG+CSS) 안에서 구현 가능해야 한다.
- 라이브러리 추가가 필요하면 먼저 확인한다.
