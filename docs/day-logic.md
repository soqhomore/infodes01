# 오전부터 밤까지의 하루 여행

2026-10-09 · 승인된 3~5분 하루 여행 및 과도한 체류 밸런스 구현 기준.

## 진행과 시간

- 09:00 출발, 21:00 귀환. 화면을 읽는 실제 시간은 게임 시각을 소비하지 않는다.
- 이동 일정은 기존 장소 도보 시간 ×3, 최소45분·최대90분이다. 압축된 일정이며 정밀 도보 시뮬레이션은 아니다.
- 9개 장소를 시드로 섞고 다음 장소·시야·이동 시간을 예고한다. 예고는 덱과 RNG를 소비하지 않는다.
- 도착하면 행동 목록·다음 장소·귀환을 바로 표시한다. 행동을 누르면 같은 화면에 30/60분 휴식과 예측을 펼친다.
- 취소하면 시간·수치·지출이 바뀌지 않는다. 무입력은 자동 휴식이 아니다.
- 통증80 이상은 이동을 잠그지만 휴식·귀환은 허용한다. 덱 소진 뒤에도 체류할 수 있다.
- 종료는 시각 도달 / 자발적 귀환 / 통증100 / 마음의 여유0이다. 방문 수를 점수나 성공 조건으로 삼지 않는다.
- 정오 이후 첫 선택 전에 한 번 식사한다. 간단한 식사 ¥800/30분, 느긋한 식사 ¥1,800/60분. 수치 회복과 분리한다.

## 회복과 과도한 체류

- 30분 기준 몸 회복: 멍때리기12 / 스마트폰8 / 디저트8 / 잡담6 / 계획4 / 돌아다니기2.
- 통증 효율은 40 미만100%, 70 미만75%, 이후50%. 회복 중 경계를 넘으면 즉시 바뀐다. 통증10 이하의 회복 속도는25%.
- 누적 휴식 첫30분의 마음 회복 효과100%, 다음30분40%, 60분 이후0%. 실제 이동1분당 누적량0.5분 해소. 행동 변경·식사·구매로 초기화하지 않는다.
- 누적60분 이상이고 현재 통증25 이하인 구간만 과도한 체류다. 몸 회복 속도를 추가로25%로 줄이고 마음의 여유를30분당4 줄인다.
- 몸이 지쳐 통증25를 넘으면 과도한 체류 불이익은 없다. 기존 높은 통증 자체의 부담은 남는다.
- 30분당 마음 회복은 0.35 × (주도성 + 시야 보너스)에 포화 배율을 적용하고, 통증 부담과 과도한 체류 부담을 별도로 더한다.
- 지출 자체는 마음·만족감 보너스를 주지 않는다. 디저트는 행동 특성과 랜덤 지출을 유지한다.
- 만족감은 이번 쉼의 마음 환기다. 기존 산식에서 금액 보너스를 제거한 0~10 값에 체류 중 평균 포화 배율을 곱한다. 총점으로 합산하지 않는다.
- 내부 정밀값을 이어 계산하고 표시만 반올림한다. 30분+30분과 연속60분의 몸·마음 효과는 같다.
- UI·실행·시뮬레이션은 같은 예측 함수를 사용한다. 예측은 RNG와 상태를 소비하지 않는다.
- 30분 후 통증25 이하면 짧게, 아니면60분의 추가 회복6 이상이면 길게 추천한다. 과도한 체류 예상 구간과 별도 마음 부담도 보여준다.
- 이동 통증 배열과 이동마다 마음의 여유−3은 유지한다. 사건은 방문 슬롯2~6에 이동 중 한 번 발생하며 첫 방문에는 없다. 구매는 예산·구매 기록만 바꾼다.

## 그래픽·리듬·기록

- 아침09~12 / 낮12~17 / 노을17~19 / 밤19~21에 하늘·빛·풍경·화면 색조가 바뀐다. 귀환도 실제 종료 시각의 빛을 사용한다.
- 이동1.5초, 도착/결과0.8초, 멍때리기3초. 이동·도착·결과는 탭으로 넘길 수 있다. 입력과 타이머는 각 화면 전환 때 정리한다.
- 표시명은 마음의 여유이며 내부 필드는 drive를 유지한다.
- 방문ID는 풍경·사건·식사를 연결하고, 개별 쉼ID는 체류 구간·실제 효과·포화량·과도한 체류 시간과 그 마음 부담을 기록한다.
- 결과는 몸 회복·마음 여유 변화·마음 환기를 구분한다. 과도한 체류 부담은 전체 변화량에 포함된 부분으로 설명해 중복 차감하지 않는다. 예전 기록도 읽을 수 있다.
- 결과 샘플 ?jump=result / 고정 시드 ?seed=123 / 상태 확인 ?debug=1.

## 자동 검증 결과

- npm test: 시간·통증·포화 경계, 분할 동등성, 예측 일치, 식사·구매·이동, 결과 호환성을 검증한다.
- npm run sim: 3여행지 ×10전략 ×100시드 =3,000세션. 전략별 종료 사유·시각·휴식 시간·통증·마음·판단·입력·연출 시간을 출력한다.
- 정상 전략 강제 종료율10% 이하, 정상 종료의 밤 도달률80% 이상을 합격 기준으로 둔다. 비용 후보4→3→2 순으로 확인하고 전부 실패하면 다른 수치를 임의로 조정하지 않는다.
- 이번 결과는 비용4 유지, 세 여행지 정상 전략 강제 종료0%, 밤 도달100%. 평균 방문7.0~7.9곳, 쉼6.0~7.3회.
- 300개 동일 경로/멍때리기/사건 없는 조건의 첫4장소 비교에서 필요한 만큼 쉬기는 이동 전 통증40 미만을 유지하며 항상 길게 쉬기보다 평균150분을 절약했다.
- 정상 전략 추정 플레이 길이는 입력당4~8초 + 생략하지 않은 연출 기준2.4~4.7분이다. 실제 사용자 측정 결과가 아니다.
- npm run build: 프로덕션 번들 검증. journal.md는 사람이 기록하므로 수정하지 않는다.
