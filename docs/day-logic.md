# 오전부터 밤까지의 하루 여행

2026-10-09 · 승인된 3~5분 하루 여행 및 과도한 체류 밸런스 구현 기준.
2026-10-11 · MVP 범위와 다음 단계 정리. 기존 수치는 변경하지 않았다.

## 문서 역할과 현재 상태

이 문서는 **현재 구현된 진행·계산·임시 수치의 기준**이다. 이번 범위·완료 조건은 [mvp.md](mvp.md), 본 계획과 이후 확장은 [plan-v2.md](plan-v2.md)를 따른다. 두 갈래 경로와 주도성 재설계는 현재 로직에 포함하지 않는다.

현재 코드는 30분 휴식 후 결과 유지, 추가 휴식·이동 비교, 같은 행동 이어 쉬기, 회복 포화·체류 부담 예측, 몸·마음 결과 구분을 구현했다. 실제 플레이의 직관성·재미·3~5분 진행과 휴대폰 조작은 사람 검증이 남아 있다. 아래 예정 항목은 아직 기능 구현 완료가 아니다.

## 진행과 시간

- 09:00 출발, 21:00 귀환. 화면을 읽는 실제 시간은 게임 시각을 소비하지 않는다.
- 이동 일정은 기존 장소 도보 시간 ×3, 최소45분·최대90분이다. 압축된 일정이며 정밀 도보 시뮬레이션은 아니다.
- 9개 장소를 시드로 섞고 다음 장소·시야·이동 시간을 예고한다. 예고는 덱과 RNG를 소비하지 않는다.
- 도착하면 행동 목록·다음 장소·귀환을 바로 표시한다. 행동 버튼에 30분 휴식과 비용 범위를 명시하며, 사전 30/60분 선택은 하지 않는다.
- 행동 인터랙션 뒤 30분을 적용하고 몸·마음의 전후 상태와 마음 환기를 보여준다. 휴식 결과는 다음 입력까지 유지한다.
- 결과에서 30분 더 쉬기와 다음 장소로 가기를 같은 비중으로 표시한다. 추가 휴식의 회복·마음 변화·종료 시각·비용 범위와 다음 장소의 이동 시간·시야를 비교할 수 있다. 다른 행동과 귀환도 가능하다.
- 같은 행동의 추가 휴식은 짧은 연출만 거치고, 다른 행동 선택은 해당 인터랙션을 다시 진행한다. 추가 휴식도 별도 30분 기록이며 유료 행동은 매번 기존 비용 규칙을 적용한다.
- 연출의 넘기기는 명시된 30분을 그대로 적용한다. 실제 대기 시간이나 조작 속도로 체류 시간이 달라지지 않는다.
- 취소하면 시간·수치·지출이 바뀌지 않는다. 무입력은 자동 휴식이 아니다.
- 통증80 이상은 이동을 잠그지만 휴식·귀환은 허용한다. 덱 소진 뒤에도 체류할 수 있다.
- 종료는 시각 도달 / 자발적 귀환 / 통증100 / 마음의 여유0이다. 방문 수를 점수나 성공 조건으로 삼지 않는다.
- 정오 이후 첫 선택 전에 한 번 식사한다. 휴식 중 정오가 되면 결과를 읽은 뒤 식사 또는 귀환을 선택하고, 식사 후 휴식·이동 판단으로 돌아온다. 간단한 식사 ¥800/30분, 느긋한 식사 ¥1,800/60분. 수치 회복과 분리한다.

## 회복과 과도한 체류

- 30분 기준 몸 회복: 멍때리기12 / 스마트폰8 / 디저트8 / 잡담6 / 계획4 / 돌아다니기2.
- 통증 효율은 40 미만100%, 70 미만75%, 이후50%. 회복 중 경계를 넘으면 즉시 바뀐다. 통증10 이하의 회복 속도는25%.
- 누적 휴식 첫30분의 마음 회복 효과100%, 다음30분40%, 60분 이후0%. 실제 이동1분당 누적량0.5분 해소. 행동 변경·식사·구매로 초기화하지 않는다.
- 누적60분 이상이고 현재 통증25 이하인 구간만 과도한 체류다. 몸 회복 속도를 추가로25%로 줄이고 마음의 여유를30분당4 줄인다.
- 몸이 지쳐 통증25를 넘으면 과도한 체류 불이익은 없다. 기존 높은 통증 자체의 부담은 남는다.
- 30분당 마음 회복은 0.35 × (주도성 + 시야 보너스)에 포화 배율을 적용하고, 통증 부담과 과도한 체류 부담을 별도로 더한다.
- 지출 자체는 마음·만족감 보너스를 주지 않는다. 디저트는 행동 특성과 랜덤 지출을 유지한다.
- 만족감은 이번 쉼의 마음 환기다. 기존 산식에서 금액 보너스를 제거한 0~10 값에 체류 중 평균 포화 배율을 곱한다. 총점으로 합산하지 않는다.
- 내부 정밀값을 이어 계산하고 표시만 반올림한다. 30분+30분과 연속60분의 몸·마음 효과는 같다.
- UI·실행·시뮬레이션은 같은 예측 함수를 사용한다. 예측은 RNG와 상태를 소비하지 않는다.
- 시뮬레이션의 기존 추천 함수는 30분 후 통증25 이하면 짧게, 아니면60분의 추가 회복6 이상이면 길게 추천한다. 플레이 화면은 더 쉬기를 추천으로 강조하지 않고 현재 상태 기준 다음30분의 효과를 보여준다. 과도한 체류 예상 구간과 별도 마음 부담은 예상 마음 변화에 포함돼 있음을 설명한다.
- 이동 통증 배열과 이동마다 마음의 여유−3은 유지한다. 사건은 방문 슬롯2~6에 이동 중 한 번 발생하며 첫 방문에는 없다. 구매는 예산·구매 기록만 바꾼다.

## 그래픽·리듬·기록

- 아침09~12 / 낮12~17 / 노을17~19 / 밤19~21에 하늘·빛·풍경·화면 색조가 바뀐다. 귀환도 실제 종료 시각의 빛을 사용한다.
- 이동1.5초, 도착/사건·식사 결과0.8초, 멍때리기3초, 같은 행동의 추가 휴식 연출0.8초. 이동·도착·사건·식사 결과는 탭으로 넘길 수 있고 휴식 연출에는 넘기기 버튼을 둔다. 일반 휴식 결과는 자동 전환하지 않으며 종료 조건 도달 시에는 기존 결과 연출 후 종료한다. 입력과 타이머는 각 화면 전환 때 정리한다.
- 표시명은 마음의 여유이며 내부 필드는 drive를 유지한다.
- 방문ID는 풍경·사건·식사를 연결하고, 개별 쉼ID는 체류 구간·실제 효과·포화량·과도한 체류 시간과 그 마음 부담을 기록한다.
- 결과는 몸 회복·마음 여유 변화·마음 환기를 구분한다. 과도한 체류 부담은 전체 변화량에 포함된 부분으로 설명해 중복 차감하지 않는다. 예전 기록도 읽을 수 있다.
- 결과 샘플 ?jump=result / 고정 시드 ?seed=123 / 상태 확인 ?debug=1.

## 다음 MVP 단계 — 예정

1. **기존 비교 화면 개선과 결과 안내 정리.** 현재 장소에 더 머물기와 다음 장소로 이동하기를 같은 비중으로 보여준다. 추가 휴식은 예상 몸·마음 변화·종료 시각·비용 범위, 이동은 다음 장소·시야·이동 시간을 표시한다. 기존 예측 함수를 사용하고 다른 행동·귀환·잠금 이유를 유지한다. 결과에서는 몸 회복·마음 변화·마음 환기·지출을 구분하고 기존 막대 상세 보기를 활용한다.
2. **간단한 개복치 상태 표현.** 기존 통증은 자세, 마음의 여유는 움직임으로 구분한다. 숫자·설명도 유지한다. 새 스탯·회복 보상·행동 효과는 추가하지 않는다.
3. **실제 플레이 검증과 필요한 수정.** 아래 사람 검증 기준과 모바일 확인을 수행한다. 각 단계는 한 번에 하나씩 진행하고 빌드 확인 후 커밋한다.

이 단계에서는 수치·API·기록 형식을 유지한다. 행동별 주도성 고정값은 현재 모델의 한계이며 조작량과 주도성을 동일시하지 않는다. 경로 분기·쉬는 방식 세부 선택과 주도성 재설계·새 회상 단계·동일한 하루 비교는 본 계획으로 미룬다.

## 남은 사용자 검증

첫 플레이 사용자3명 이상에게 결과 감상 제외 시간을 측정한다. 시작은 여행지 선택, 종료는 하루 기록 화면 진입이다. 안내 없이 플레이하게 하고 아래를 기록한다.

- 실제 소요 시간 / 선택에서 막힌 지점 / 긴 휴식을 고른 이유 / 과도한 체류 뒤 마음이 줄어든 이유를 설명할 수 있는지.
- 몸·마음 상태 표현을 구분하는지 / 결과의 몸 회복·마음 환기·지출을 구분하는지 / 지출과 휴식 가치의 관계를 어떻게 해석하는지 / 재미를 느낀 순간.
- 휴대폰 배포 URL에서 터치·드래그·넘기기·취소·반복 체류·식사·귀환·기록 상세를 조작해 끝까지 진행할 수 있는지.
- 첫 플레이 중간값3~5분, 필요한 긴 휴식과 불필요한 반복 체류를 구분하는 사용자3명 중2명 이상이 목표다.
- 아직 사람의 플레이 테스트는 실시하지 않았다. 체감 재미·3~5분 달성은 자동 테스트 통과와 별개다.
